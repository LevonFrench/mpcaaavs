aaavs

A Winamp AVS compatibility studio. Feed it audio, inspect the real ordered effect graph, and let the director cut presets on the bar.

Photosensitivity warning. Many AVS presets flash, strobe and flicker, and some can trigger seizures in people with photosensitive epilepsy. Flash limiting is on by default in this window (FLASH LIMIT, bottom right) and always on in the projector window. It reduces large flashes; it does not guarantee a safe picture. Stop watching if you feel unwell.

Projector

Oopen a second window that shows only the visuals — no HUD, no panels, no hint bar. Drag it to the second display and fullscreen it.
howthe projector renders the show itself, on its own GPU device, from the preset and one packed audio frame per frame. A canvas cannot be moved between windows, so the description travels instead of the picture — no re-encode, no added latency.
this windowdims its stage while the projector holds the output, so it is obvious where the show went. Every control still works here.
either windowcan be closed or reloaded at any time. They find each other again; audio is analysed once, here.

AVS display

Uupscale: pixelated (default) · sharp-bilinear (identical on 1080p/1440p/4K, even pixels on 16:10 and projector panels) · integer letterbox
VAVS raster: classic 640 · crisp integer-fit · high (2×, steps back to classic under load). Crisp and high render a different raster, so pixel-sized effects look different.
Fframe rate: display · 60 · 30 locked. AVS presets animate per frame, so a lock also sets their speed.
both windowsthe choice is remembered and the projector follows it. The HUD (H) shows what is actually in effect.
FLASHflash limiting for this window: limit (default) · strict · off. Remembered. The projector is always limited, whatever this says.
GPU EXACTAVS output is bit-exact by default. GPU APPROX allows faster approximate GPU effects in both windows; the preset restarts when it changes.

Step grid

S16-step trigger lanes on the audio clock. Click a cell to write a step; the playhead follows the same 1/16 grid the layers do.
targeteach lane picks one live target — the same list I binds MIDI to. The slider is the value a step hands it.
resta lane parked on rest fires nothing on purpose. Silence is a written choice, not an empty row.
precedencea lane that changes presets takes them over: automatic preset changes stop while it has steps written.
tempothe grid stays silent until tempo locks. It will not run on the assumed 120 BPM — a written rhythm on a guessed grid is worse than none.
